# Part A local smoke scripts

`CPU_Smoke.tst` and `Memory_Smoke.tst` are starter scripts for a quick local simulator run. They create `.out` traces and are useful for checking that the HDL loads and basic pin operations execute.

They are **not** the official course test suites and do not replace the official `.tst`/`.cmp` files. Obtain `CPU.tst`, `CPU.cmp`, `Memory.tst`, `Memory.cmp`, and the Computer integration test files from the course distribution before claiming official verification.
